Where the games come from, how they are built, and what makes this project different from the usual browser-game churn.

What Is Mini Game Arcade?

Mini Game Arcade is an independent collection of original browser-based arcade games. Every game here is purpose-built — coded from scratch, playable immediately in any modern browser, and free to use with no account required.

There are no third-party game engines, no asset stores, and no borrowed artwork. Each game — from the canvas rendering to the sound design — is written by hand using standard web technologies: HTML, CSS, and vanilla JavaScript.

Why Build This?

Most free browser-game sites are aggregators: they host games made elsewhere, wrap them in cookie banners, and monetise the experience with overlapping ad layers. This project takes the opposite approach. Fewer games, made carefully, with gameplay as the only priority.

The goal is to demonstrate that a tight, satisfying arcade experience does not require a 50 MB game engine, a CDN-hosted asset pack, or a third-party ad network. A well-written canvas loop and a coherent design system are enough.

Technology

Every page on this site is a static HTML file. There is no server-side rendering, no build pipeline, and no JavaScript framework. The only external dependency is Google Fonts for typography.

Each game is a self-contained folder: one HTML file, one CSS file, and one JS file. Audio uses the Web Audio API — synthesised entirely in code, no audio files to download. Graphics use the Canvas 2D API.

Deployable anywhere: Because everything is static, the entire site can be deployed on Vercel, Netlify, GitHub Pages, or any basic web host by dragging a folder.

What Games Are Available?

Currently one game is live: Skyline Shift — a neon lane-runner where you race a hoverboard through a cyberpunk city grid, dodging security gates and collecting energy orbs. More games are in development and will appear on the homepage as soon as they are ready. No placeholder cards, no "coming soon" fakes.

Honesty Policy

This site does not display fake player counts, inflated review scores, or invented testimonials. The stats shown on the homepage (1 game, 0 ads, always free) are accurate and will be updated as the project grows.

Contributing or Suggesting a Game

If you have an idea for a game that would fit the arcade style, use the contact page to get in touch. Developers interested in contributing should read the README.md in the project root, which explains exactly how to add a new game to the arcade.
