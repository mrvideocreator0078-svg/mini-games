# Cyber Slicer: Neon Blade

**Cyber Slicer** is a high-octane kinetic cyberpunk blade slicing action game built with 100% Vanilla JavaScript, native HTML5 Canvas, and the Web Audio API.

---

## 🎮 Gameplay & Features
- **Kinetic Physics Engine:** Trajectory arcs, velocity vectors, rotation, and realistic geometric slicing that bisects polygons into two physically reactive halves.
- **Matrix Bullet-Time:** Slicing golden Chrono Cubes decelerates global game simulation to 35% speed for intense multi-target chaining.
- **3 Game Modes:**
  - **Arcade Protocol:** 3 lives, avoid lethal red firewall bombs, missed cores cost lives.
  - **Zen Flow:** 60-second time trial without bombs or life penalties.
  - **Hyper Rush:** Rapid-spawn escalating survival challenge.
- **Cyber Arsenal:** Unlockable katanas with distinct trail colors and glow shaders (Cyan Plasma, Crimson Katana, Solar Arc, Void Shadow).
- **Web Audio API Sound Engine:** Velocity-scaled blade swoosh synthesis, metal blade clashes, pentatonic combo fanfare, and sub-bass explosions.
- **Local Persistence:** High scores, Cyber Credits 💎, and equipped blades saved locally in `localStorage.getItem('cyber_slicer_save_v1')`.
